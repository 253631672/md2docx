# md2docx —— Markdown 转 Word，零依赖单文件

把手机上写的笔记、AI 导出的 Markdown、仓库里的 README，一条命令转成能直接发给领导或客户的 `.docx`。
只用 Python 标准库手写 OOXML，不装 python-docx、不装 Office、不联网、不上传文件。

```bash
python3 md2docx.py 笔记.md                 # 生成 笔记.docx
python3 md2docx.py 周报.md -o 门店周报.docx --title "门店周报" --author "Marco"
```

## 为什么不用在线转换

在线工具要登录、限页数、限文件大小，而且你的周报、客户名单、门店数据等于交给陌生人。
Word 另存为又得装 Office。这个脚本只读本地文件，输出一个 zip 结构的 docx，全程离线，速度在几百毫秒级。

## 支持什么

| Markdown | 转成 Word 后 |
|---|---|
| `#` ~ `######` | 标题1-6，带大纲级别，Word 导航窗格可直接跳转（长文按章节翻页） |
| 普通段落、空行 | 正文分段，1.5 倍行距 |
| `-` `*` `+` 列表（可缩进） | 项目符号列表，缩进层级保留 |
| `1.` `1)` 列表 | 有序列表，编号原样保留 |
| `\| a \| b \|` 表格 | 真 Word 表格，首行加底色加粗，列宽按内容长短分配 |
| ` ``` ` 代码块 | 等宽字体 + 浅灰底，缩进不丢 |
| `> 引用` | 左缩进 + 灰色斜体 |
| `**粗体**` `*斜体*` `` `等宽` `` | 对应字符格式 |
| `[文字](链接)` | 保留文字，把地址附在括号里（本地打印也能看到出处） |
| `---` | 分页符 |

中文、英文、数字混排都正常；中文表格列宽按 2 个字符宽度计算，不会把「平台」列撑成一整行。

## 参数

| 参数 | 作用 | 默认 |
|---|---|---|
| `-o, --output` | 输出路径 | 同名 `.docx` |
| `--font` | 正文字体 | 等线 |
| `--mono` | 代码字体 | Consolas |
| `--size` | 字号(pt) | 10.5 |
| `--margin` | 页边距(twips，1134≈2cm) | 1134 |
| `--landscape` | 横向页面，宽表格用 | 关 |
| `--title` | 文档标题属性 | 取一级标题或文件名 |
| `--author` | 作者属性 | md2docx |
| `--check` | 只体检不写盘：行数、字数、标题/表格/代码块/列表数量 | 关 |

## 三个真实场景

**1. 门店周报从笔记变正式文档**
```bash
python3 md2docx.py 本周笔记.md -o 门店周报.docx --title "门店周报：三平台流量与核销" --author "Marco"
```
数据表、动作清单、下周计划都在，直接发群里，不用再复制到 Word 重排一遍。

**2. 宽表格用横向**
```bash
python3 md2docx.py 报价对比.md --landscape --size 9
```
五六列的价格、规格对比，竖版会被挤得换行，横向正好。

**3. README 变交付文档**
```bash
python3 md2docx.py README.md -o 工具说明.docx --font 微软雅黑 --size 11
```

## 常见问题

**Q：Word 打开提示格式错误？**
不会。生成的是标准 OOXML（`[Content_Types].xml` + `word/document.xml` + `word/styles.xml`），Word 2010 以上、WPS、macOS Pages 都能打开。如果真打不开，说明文件被改坏了，重新跑一次。

**Q：字体不对 / 想换成宋体？**
`--font 宋体`。字号同理 `--size 12`。这两个值写进 `styles.xml` 的 docDefaults，全篇统一生效。

**Q：中文乱码？**
脚本会依次试 UTF-8、GB18030、Big5，Windows 记事本存的 GBK 文件也能读。注意是「读」不乱码，输出永远是 UTF-8，Word 显示正常。

**Q：图片呢？**
这一版不处理 `![](图片)`，图片语法会被当普通文字留下。需要图文混排就用 Word 自己插；下一版再加图片嵌入。

**Q：表格列宽怪？**
按每列最长内容的显示宽度分配，中文字算 2 格。想让某列更宽，就在该列内容里写长一点，或者用 `--landscape`。

**Q：为什么不支持脚注、公式、目录？**
这三样要额外的 OOXML 部件（footnotes.xml、OMML、TOC 域），加上会让「单文件零依赖」变复杂。这一版先保证 90% 的日常文档：标题、正文、列表、表格、代码。

## 交付内容

- `md2docx.py` 主程序，单文件，约 400 行，纯标准库
- `README.md` 本文档
- `example/demo.md` + `example/run.sh` 一个可直接跑的示例
- 买断制，源码可改可自用，不限制生成份数

## 限制（提前说清）

- 只做 Markdown → Word 单向转换，不反向读 docx
- 不支持插入图片、脚注、公式、自动目录
- 不生成 .doc（97-2003 旧格式），只出 .docx
- Python 3.8 及以上，Windows / macOS / Linux 通用
